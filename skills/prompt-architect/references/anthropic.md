# Anthropic: where to read

Covers Claude, Claude Code, and the Claude API. This file lists pages to read. It does not say what they contain; read the pages themselves.

## Where to start

1. Prompting best practices.
2. The model's own pages, once you know the model: `prompting-claude-<model>`, `models/<model>/overview`, and `models/<model>/whats-new-<model>`. Not every model has all three.
3. The effort and thinking pages, if the model's pages point to them or the task depends on reasoning settings.

## Which page to check for each point

The first six rows are the points Step 5 asks for; any later row covers a specific case. Start with the page named here; if it does not cover the point, check the other general guides before saying the point was not covered. The pairing follows the page titles and is a starting point, not a summary of the pages.

| Point (Step 5) | Start with |
|---|---|
| Which model a product uses | The model overview pages; Migration guides (index) |
| How to structure the prompt | Prompting best practices · `prompting-claude-<model>` |
| Reasoning or effort controls | Effort parameter · Steering thinking · Extended thinking |
| Instructions to remove or avoid for this model | `prompting-claude-<model>` · `whats-new-<model>` · Migration guides |
| Output formatting | Prompting best practices · `prompting-claude-<model>` |
| Preview, beta, or legacy status | The model overview page; notices at the top of the effort and thinking pages |
| Context and tools for an agent | Effective context engineering for AI agents |
