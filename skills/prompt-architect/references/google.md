# Google: where to read

Covers Gemini, the Gemini API, and Vertex AI. This file lists pages to read. It does not say what they contain; read the pages themselves.

## Where to start

1. Prompt design strategies.
2. The latest model page, then the page for the exact model once you know it.
3. The thinking page, if the task depends on reasoning settings.
4. For prompts set as system instructions on Vertex AI, the system instructions page.

## Which page to check for each point

The first six rows are the points Step 5 asks for; any later row covers a specific case. Start with the page named here; if it does not cover the point, check the other general guides before saying the point was not covered. The pairing follows the page titles and is a starting point, not a summary of the pages.

| Point (Step 5) | Start with |
|---|---|
| Which model a product uses | Latest model · the model's page |
| How to structure the prompt | Prompt design strategies · System instructions (Vertex AI) |
| Reasoning or effort controls | Thinking |
| Instructions to remove or avoid for this model | Latest model · the model's page |
| Output formatting | Prompt design strategies |
| Preview, beta, or legacy status | The model's page · the model card |
